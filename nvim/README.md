### Prerequisites

* Nerd Font
    * Install
        * `brew install --cask font-hack-nerd-font` (or another font of your choosing)
    * Use
        * In ITerm2: Settings > Profiles > Text > Font (and also set the vertical spacing to 115)
* Ripgrep
* Node & npm (for ts_ls)
* Treesitter - as of Neovim 0.12.0, requires CLI (`brew install tree-sitter-cli`) and a C compiler on your path (eg clang)
